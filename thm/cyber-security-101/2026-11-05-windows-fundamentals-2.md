# Windows Fundamentals 2

## TL;DR

Системные встроенные утилиты Windows: работа с конфигурацией системы (`msconfig`), управление UAC, консоль `Computer Management`, анализ системы через `msinfo32`, мониторинг ресурсов (`resmon`), основы командной строки `cmd` и устройство реестра Windows (`regedit`).

## Что нужно было знать заранее

Базовые понятия из первой части (Windows Fundamentals 1): устройство интерфейса Windows, права пользователей, отличие обычных прав от административных и базовый синтаксис выполнения команд.

## Ход решения

### 1. Конфигурация системы (System Configuration — `msconfig`)

Утилита `msconfig` используется для управления параметрами загрузки ОС, службами и элементами автозапуска.

* Позволяет отключать ненужные службы, выбирать типы загрузки (Safe Boot, Diagnostic Boot) и быстро переходить к ключевым утилитам администрирования.
* Службы в этом разделе можно фильтровать, скрывая системные службы Microsoft, чтобы находить стороннее ПО.

### 2. Настройка UAC (User Account Control Settings)

Параметры контроля учётных записей регулируются утилитой `UserAccountControlSettings.exe`.

* Шкала UAC содержит 4 уровня уведомительного контроля: от "Always notify" (максимальная защита) до "Never notify" (отключение уведомлений, снижение безопасности).

### 3. Управление компьютером (Computer Management — `compmgmt.msc`)

Один из главных snap-in инструментов системного администратора, объединяющий несколько оснасток:

* **Task Scheduler (Планировщик задач):** управление автоматически запускаемыми заданиями по расписанию или триггерам (например, при входе в систему — `At logon` или `At system startup`).
* **Shared Folders (Общие папки):** просмотр активных сетевых шар, подключенных сессий и открытых файлов. Скрытые административные шары обозначаются знаком `$` в конце имени.
* **Local Users and Groups:** локальное управление пользователями и группами.

### 4. Сведения о системе (System Information — `msinfo32.exe`)

Утилита `msinfo32` предоставляет подробный отчёт об аппаратной и программной конфигурации ПК.

* Содержит свежие данные об установленной версии ОС, BIOS/UEFI, именах хоста, объёме ОЗУ, а также переменные окружения (Environment Variables), такие как `ComSpec` (путь к командному интерпретатору по умолчанию).

### 5. Монитор ресурсов (Resource Monitor — `resmon.exe`)

Инструмент для глубокого анализа использования ресурсов в реальном времени.

* В отличие от обычного Диспетчера задач, `resmon` позволяет детально отслеживать нагрузки по вкладкам: CPU, Memory, Disk и Network (включая просмотр сетевых соединений и открытых портов конкретными процессами).

### 6. Командная строка (Command Prompt — `cmd.exe`)

Интерфейс командной строки Windows для выполнения системных команд и скриптов.

* Основные утилиты диагностики сети: `ipconfig` (вывод сетевых настроек) и `ipconfig /all` (расширенная информация с MAC-адресами, DHCP и DNS).

### 7. Редактор реестра (Registry Editor — `regedit.exe`)

Иерархическая база данных настроек операционной системы и установленных программ.

* Реестр состоит из 5 основных ветвей (HKEY):
  * `HKLM` (HKEY_LOCAL_MACHINE) — настройки для всего компьютера.
  * `HKCU` (HKEY_CURRENT_USER) — настройки текущего вошедшего пользователя.
  * `HKCR`, `HKU`, `HKCC` — ассоциации файлов, профили пользователей и текущая аппаратная конфигурация.

## Где я застрял

* Разница между `msconfig` и `msinfo32`: первая утилита нужна для управления загрузкой и службами, вторая — исключительно для просмотра информации о системе.

## Что понял

* Переменная `ComSpec` задаёт системный командный толмач (по умолчанию `cmd.exe`).
* В реестре хранятся почти все глобальные и пользовательские конфиги Windows; изменение веток `HKLM` требует прав администратора.
* `resmon` — ключевой инструмент для быстрого обнаружения подозрительной сетевой активности процессов без установки стороннего софта.
