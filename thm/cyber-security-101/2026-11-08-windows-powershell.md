# Windows PowerShell

> **Платформа:** TryHackMe · **Путь:** thm/cyber-security-101 · **Модуль:** Command Line · **Сложность:** Normal · **Дата:** 2026-11-08

## TL;DR

Основы работы с Windows PowerShell: командлеты (Cmdlets), псевдонимы (Aliases), встроенная справочная система, манипуляция файлами и объектами, фильтрация данных через конвейер (Pipeline), удаленное управление (PSRemoting) и базовый сбор информации о системе.

## Что нужно было знать заранее

Базовые принципы работы с командной строкой Windows (`cmd.exe`) и концепция объектно-ориентированного подхода (PowerShell передает между командами объекты, а не просто текстовые строки).

## Ход решения

### 1. Поиск команд и справочная система

PowerShell использует стандартизированную структуру наименования командлет: `Глагол-Существительное` (например, `Get-Process`).

* `Get-Command` — поиск доступных командлетов и псевдонимов. Позволяет фильтровать по глаголам или существительным с помощью масок (например, `Get-Command -Name Remove*`).

* `Get-Help` — справка по командам. Флаг `-examples` отображает практические примеры использования командлета.

> * **Aliases (Псевдонимы):** привычные команды из Linux/CMD работают как ссылки на командлеты (например, `echo` — это псевдоним для `Write-Output`, `ls` или `dir` — для `Get-ChildItem`, `cat` / `type` — для `Get-Content`).

### 2. Навигация и работа с файлами

* `Get-ChildItem` — просмотр содержимого каталогов.

* `Get-Content` — чтение содержимого файлов.

* `Get-FileHash` — вычисление хэш-суммы файла (по умолчанию SHA-256) для проверки его целостности.

### 3. Конвейер и фильтрация объектов (Pipeline & Filtering)

В PowerShell символом `|` передаются не строки текста, а полноценные `.NET`-объекты со своими свойствами и методами.

* `Where-Object` — фильтрация объектов на основе условий. Используются операторы сравнения: `-eq` (равно), `-ne` (не равно), `-gt` (больше), `-lt` (меньше), `-like` (сопоставление по маске) и др.

* `Select-Object` — выборка конкретных свойств у объектов.

### 4. Управление системой, службами и сетью

* `Get-LocalUser` и `Get-LocalGroup` — инспекция локальных пользователей, их описаний и статусов (включена/отключена учетная запись).

* `Get-Service` — просмотр списка служб и их состояния (Running/Stopped).

* `Get-NetTCPConnection` — получение списка сетевых подключений. Свойство `OwningProcess` содержит PID процесса, открывшего соединение.

### 5. Удаленное администрирование (PSRemoting)

Выполнение команд на удаленных хостах в домене или сети:

* `Invoke-Command` — запуск скрипта или командлета на одном или нескольких удаленных компьютерах. Применяется параметр `-ComputerName` и блок кода `-ScriptBlock { ... }`.

* `Enter-PSSession` — открытие интерактивной сессии PowerShell на удаленной машине.

## Где я застрял

* Синтаксис операторов сравнения: вместо привычных знаков `>` или `<` в PowerShell используются `-gt`, `-lt`, `-eq`, что требует некоторой привычки при формировании условий в `Where-Object`.

* Разница между строками и объектами: при попытке передать результат выполнения в другую команду важно обращаться к конкретному свойству объекта (например, `.OwningProcess` или `.Length`).

## Что понял

* Конвейер объектов делает PowerShell несоизмеримо более мощным инструментом по сравнению с `cmd.exe`: отпадает необходимость парсить вывод через `findstr` или регулярные выражения.

* Встроенная справка `Get-Help <cmdlet> -examples` позволяет быстро научиться использовать любую незнакомую команду прямо из терминала.

* PSRemoting (`Invoke-Command`) — базовый инструмент администрирования инфраструктуры Windows и продвижения по сети (Lateral Movement) в контексте безопасности.

## Если бы делал заново

* Использовал бы `Get-Member` сразу при работе с незнакомыми командами, чтобы мгновенно увидеть все доступные свойства и методы объекта.
