## Ход решения

### 1. Инструмент Shodan

Как я понял нужен для сканирования интернета в поисках различного сетевого оборудования, всякие дорожные камеры и все остальные устройства которые имею подключение к сети общего доступа.

Также есть фильтрация для сужения круга поиска, фильтровать можно по стране, порту, организации, и хостнейму.

### 2. Мини игра TryScanMe

Нужно ввести имя apache(тип веб сервера) в строку поиска и найти указанное айпи и посмотреть какой домен с ним связан.

### 3. Инструмент VirusTotal

Достаточно много объединяет, 70 антивирусных систем на одном сайте.

Пользуется популярностью у (blue team) для получения общего консенсуса по подозрительным файлам и ссылкам, а также для сбора разведданных о новых угрозах на ходу.

Также если нужно проверить файл не загружая его, можно предоставить хэш файла, т.к. поиск по хэшу возвращает существующие результаты для данного конкретного образца, не раскрывая его содержимого.

### 4. Мини игра TryDetectMe

В поиске нужно ввести название файла .exe и страница покажет информацию о нем, сколько поставщиков средств пометили файл как вредоносный и прочая информация.

### 5. Vulnerability Databases

Любые подтвержденные уязвимости получают свой идентификатор CVE-YEAR-NUMBER, если уязвимость сильно эффективна, она может получить прозвище.

Таким уязвимостям присваивается оценка CVSS на основе факторов воздействие, сложность и доступность.

### 6. Мини игра CVE (Common Vulnerabilities and Exposures)

Нужно выполнить поиск в базе данных уязвимостей для определенного идентификатора и найти CVSS подсчет очков.

## Что понял

- Техническая документация ваш главный друг. При устранении неполадок или изучении инструмента она должна быть нашей первой остановкой, а не последней.
- Чтобы посмотреть страницу руководства команды в терминале линукс нужна команда ```man <command>```
- На GitHub также можно просматривать репозитории с описанием и демонстрацией уязвимостей по кодам CVE.
