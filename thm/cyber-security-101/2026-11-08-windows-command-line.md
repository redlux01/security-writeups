# Windows Command Line

> **Платформа:** TryHackMe · **Путь:** thm/cyber-security-101 · **Модуль:** Windows Fundamentals · **Сложность:** Easy · **Дата:** 2026-11-08

## TL;DR

Основы работы с классической командной строкой Windows (`cmd.exe`): базовый синтаксис, навигация по файловой системе, управление файлами и папками, сетевая диагностика, сбор системной информации и управление процессами.

## Что нужно было знать заранее

Понимание базовой структуры файловой системы Windows (`C:\`, пути с обратным слэшем `\`), а также концепции прав пользователей (обычный пользователь vs Администратор).

## Ход решения

### 1. Навигация и вывод информации

Командная строка использует стандартные встроенные утилиты для взаимодействия со средой:

* `dir` — просмотр содержимого текущей или указанной директории. Флаги `/a` позволяют отображать скрытые и системные файлы.
* `cd` — смена текущей директории. Переход на другой диск осуществляется вводом буквы диска с двоеточием (например, `D:`).
* `type` — вывод содержимого текстового файла в консоль (аналог `cat` в Linux).
* `cls` — очистка экрана консоли.

### 2. Управление файловой системой

Создание, копирование, перемещение и удаление объектов:

* `mkdir` / `md` — создание новой директории.
* `type nul > filename` или `echo text > filename` — создание файла.
* `copy` — копирование одного или нескольких файлов.
* `move` — перемещение или переименование файлов и каталогов.
* `del` / `erase` — удаление файлов.
* `rmdir` / `rd` — удаление папок (флаг `/s` удаляет папку со всем её содержимым).

### 3. Сетевая диагностика

Утилиты `cmd.exe` для проверки сетевой связности и конфигурации интерфейсов:

* `ipconfig` — отображение IP-адресов, масок подсети и шлюзов по умолчанию. С флагом `/all` выводит полную информацию (MAC-адрес, DHCP, DNS).
* `ping` — проверка доступности узла по протоколу ICMP.
* `netstat` — отображение активных сетевых соединений, прослушиваемых портов и таблиц маршрутизации.
* `nslookup` — отправка DNS-запросов для резолвинга имён и проверки DNS-серверов.

### 4. Инспекция системы и работа с процессами

Инструменты для анализа окружения и активных программ:

* `systeminfo` — подробная сводка об операционной системе, включая имя хоста, версию сборки, архитектуру, установленные исправления (hotfixes) и сетевые адаптеры.
* `tasklist` — список всех запущенных процессов с их именами, PID (Process ID) и использованием памяти.
* `taskkill` — принудительное или мягкое завершение процессов (например, по PID с помощью `/PID <id>` или по имени через `/IM <processname.exe>` с флагом `/F` для принудительного закрытия).

### 5. Сетевое администрирование с помощью `net`

Семейство команд `net` для управления локальными учетными записями, группами и ресурсами:

* `net user` — просмотр и управление локальными пользователями.
* `net localgroup` — просмотр и управление локальными группами (например, добавление пользователя в группу `Administrators`).
* `net share` — отображение и создание общих сетевых ресурсов (шар).

## Где я застрял

* Переключение между дисками: команда `cd D:\Folder` изменит путь на диске D, но не переключит текущий активный диск. Сначала нужно выполнить `D:`.

## Что понял

* Утилита `cmd.exe` остаётся фундаментальным инструментом для быстрой первичной разведки (reconnaissance) на машине Windows при ограниченном доступе или отсутствии PowerShell.
* Команда `systeminfo` — один из первых шагов при сборе информации о системе для поиска отсутствующих патчей безопасности.
* Встроенные команды семейства `net` позволяют быстро оценить состав пользователей и локальные привилегии.

## Если бы делал заново

* Использовал бы комбинацию `tasklist` и `findstr` для быстрого поиска конкретного процесса вместо ручного просматривания всего списка.
