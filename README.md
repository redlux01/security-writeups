## Зачем этот репозиторий

Это не коллекция флагов. Это журнал того, **как я думаю**.

Каждая запись — комната или задача, разобранная до состояния «могу объяснить без заметок». Если объяснить не могу — значит не понял, а просто прочитал.

Три вещи, которые репозиторий делает одновременно:

1. **Учёба.** Объяснять — лучший способ понять. Метод Фейнмана, только с коммитами.
2. **Портфолио.** На собеседовании это работает лучше строчки в резюме, потому что видно ход мысли.
3. **Прогресс.** Часы врут. Артефакты — нет. Зелёные квадратики не врут.

## 🚀 Как добавить райтап

### Вариант А — скриптом (30 секунд)

```powershell
.\new-writeup.cmd -Area thm\pre-security -Name "Offensive Security Intro"
```

Создаст файл `thm/pre-security/2026-10-30-offensive-security-intro.md` из шаблона, с уже подставленной датой и названием. Дальше просто заполняешь.

> `.cmd`-обёртка нужна, потому что Windows по умолчанию блокирует `.ps1`-скрипты. Она обходит это только для себя и ничего не меняет в системе.

### Вариант Б — руками

1. Скопируй [`TEMPLATE.md`](TEMPLATE.md)
2. Положи в нужную папку, назови `ГГГГ-ММ-ДД-название.md`
3. Заполни

### Потом — в любом случае

**Одной командой:**

```powershell
.\publish.cmd "thm: offensive security intro"
```

Скрипт сам обновит статистику, закоммитит и запушит.

**Или вручную, если хочешь контролировать:**

```powershell
git add .
git commit -m "thm: offensive security intro"
git push
```

Всё. Квадратик на гитхабе загорится сам.

> 📊 **Статистика** обновляется автоматически после пуша (GitHub Actions). Если она вдруг не обновилась — запусти вручную: `python scripts/update_stats.py`, потом закоммить README.

> ⚠️ **Важно:** коммиты должны идти с email, который привязан к аккаунту GitHub. Иначе квадратики не загорятся. В этом репозитории уже настроен `noreply`-адрес GitHub, он засчитывается всегда: `git config user.email`

## 🗂 Структура

| Папка | Что внутри |
|---|---|
| `thm/` | Райтапы комнат TryHackMe, разложены по путям |
| `ctf/` | Задачи с CTF-площадок (picoCTF, HTB, ивенты) |
| `tools/` | Мои скрипты: сканеры, парсеры, автоматизация |
| `notes/` | Концепты, которые разобрал: сети, Linux, веб, AD |

Внутри `thm/` папки соответствуют путям TryHackMe. Нет нужной папки — просто создай, скрипт это умеет сам.

```
thm/
├── pre-security/
├── intro-to-cyber-security/
├── network-fundamentals/
├── web-fundamentals/
├── jr-pentester/
├── soc-level-1/
└── cyber-defense/
```

## ✍️ Что писать, чтобы это имело ценность

**Пиши про ход мысли, а не про ответ.**

Плохо:
> Открыл страницу, нашёл флаг в исходнике. Флаг: `THM{...}`

Хорошо:
> Проверил `robots.txt` — пусто. Посмотрел исходник главной — заметил комментарий `<!-- backup -->`. Запросил `/backup/` — 403, но размер ответа отличается от обычной 403. Значит директория существует. Дальше перебор через `gobuster` с `-x php,zip` нашёл архив. Вывод: 403 — это не «нет», а «есть, но не тебе».

Второе читают. Первое — нет. И второе ты сам перечитаешь через полгода и вспомнишь.

**Три правила:**

- Команды — в блоках кода, с пометкой, что именно ты искал
- Обязательный раздел «Где я застрял» — он ценнее всего остального
- Одна запись = один главный вывод. Не пытайся уместить всё

**Чего не делать:**

- ❌ Не публикуй флаги и полные решения **активных платных** комнат — это нарушает правила платформы
- ❌ Не выкладывай чужие слитые материалы и чужие райтапы
- ❌ Не пиши «как взломать реальный сервис» — только лаборатории, CTF и своя лаба
